# ☕ Phase Coffee Factory  
**Official fork of the Phase Connect Coffee Factory series modpack**

A refined, actively maintained fork of the original Phase Connect Coffee Factory modpack as seen in WISH Invaders Phase Coffee Factory series.  
This version focuses on stability, performance, and a smoother progression experience with fewest possible changes to preserve the spirit of the original pack.

---

## 📦 Features

- **Fully up to date mods and recipes** Including popular add-ons and quality of life improvements
- **Improved configs** for performance and balance ("and breasts" - copilot)  
- **FancyMenu integration** with custom UI elements
- **Resource packs & global packs** included for a consistent visual experience  
- **KubeJS scripts** for custom recipes, tweaks, and progression adjustments  

---

## 🚀 Installation

### 🖥️ MultiMC / PolyMC / Prism Launcher
1. Download the latest release from the [Releases](https://github.com/NeoRussia/PhaseCoffeeFactory/releases) page.  
2. Import the `.zip` pack into your launcher.  
3. Launch and enjoy your coffee‑powered automation journey.

### 🔧 Packwiz (Advanced Users)
If you prefer Packwiz:
```bash
packwiz serve
```
Then import the generated URL into your launcher.

## 📁 Project Structure

| Folder | Purpose |
|--------|---------|
| `config/` | Mod configuration files |
| `defaultconfigs/` | Default configs applied on first launch |
| `kubejs/` | Custom scripts, recipes, and tweaks |
| `fancymenu_data/` | Custom UI elements |
| `mods/` | Packwiz‑managed mod definitions |
| `resourcepacks/` | Built‑in resource packs |
| `global_packs/required_resources/` | Required global assets |
| `Jelly's cooked options.txt` | The original options.txt included with the pack |
